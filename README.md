I need you to build a prototype for me which has 4 buttons: DISABLE USB, ENABLE USB, VIEW LOGS, PROJECT INFO. The output must look similar to the screenshot. when clicked on project info, it should redirect to a web page that consists of project details. I have also attached the list of enhancements required. The buttons need to have icons and logos. The prototype must have a logo when launched and also a faded logo when working.
